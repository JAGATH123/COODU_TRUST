# About → "Our Reach" section — data provenance

Real, verified data behind the About-page comparison viz (two globes + chart).
**Do not change these numbers without re-verifying.**

**Framing:** Dindigul district (COODU's home) vs Tamil Nadu (state average).
**Survey:** National Family Health Survey (NFHS-5), 2019–21 — MoHFW / IIPS.

| Indicator (higher = better) | Dindigul | Tamil Nadu |
|---|---|---|
| Improved drinking water source | 99.5% | 98.6% |
| Improved sanitation facility | 61.0% | 72.6% |
| Clean cooking fuel | 76.3% | 82.9% |
| Households with electricity | 98.8% | 99.3% |
| Women literate (15–49) | 78.2% | 84.0% |
| Institutional births | 97.0% | 99.6% |
| Children 12–23m fully vaccinated | 92.6% | 89.2% |

Honest note: Dindigul *leads* the state on drinking water + child vaccination, is near-parity on electricity, and *trails* on sanitation, clean fuel, female literacy, institutional births — those gaps map to COODU's program areas.
